[상호운용성]
- 운용성확인 4개 결과범주를 ‘평가항목별 결과 구분’으로 명확화
- 적합 / 주요 결함사항 / 도출된 문제점 / 개선 및 발전사항의 의미 설명

- 탐색개발·체계개발·구매사업별 평가를 전체 문장으로 구분

[부품국산화]
- 2·4·3·1 암기어 제거, 10개 개발유형의 명칭과 목적을 직접 표시
- 소공선협관평활 제거 → 지원사업 절차 전체 표시
- 소타승협개시완 제거 → 대표 개발 절차 전체 표시
- 승인기관과 관리기관을 유형별로 직접 표시
- 10번째 ‘부품성능개량’은 제4조 승인·관리기관 표와 별도 절차임을 명시
- 50/60/70% 국산화인증 기준을 적용대상과 연결
- ‘30%+핵심품목’ 의미를 공통 추가요건으로 풀어씀
- 지원사업 최종평가 판정명을 현행 ‘성공 / 성실수행 / 실패’로 교정하고 판단기준 추가
- 오답1~5 번호식 표현 제거 → ‘잘못된 설명 → 바른 기준’ 대응형으로 변경
- 확인서 3종 별도 카드 추가: 연구개발확인서 / 부품성능확인서 / 상생협력확인서
- 상생협력부품국산화 지원 체계업체 등의 특별 발급규칙 반영
